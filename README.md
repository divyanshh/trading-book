# Morning Book

The equity-service daily report, one page per trading day, mirrored here every evening
from the service's public `/api/v1/reports/` endpoint (no credentials involved) and served
by GitHub Pages. `latest.html` always opens the newest; `index.html` lists
every day by month with its gate verdict.

Public by the owner's decision (2026-09-23). The pages carry the tenant's sizing and, on
live days, positions and stop levels.
